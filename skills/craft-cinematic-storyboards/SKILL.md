# 世界级电影分镜设计

## 目标

把剧本中的选择、信息和动作变成观众实际经历的镜头顺序。分镜不是给文字配四张漂亮插图，而是控制观众站在哪里、何时知道什么、怎样跨越空间、在哪个动作点切镜，以及相邻画面如何通过视线、方向、形状、声音或情绪相连。

本 skill 决定镜头功能、机位关系、景别、运动、构图、轴线与剪辑，不负责重新写故事，不重做资产，也不输出最终高密度摄影/VFX 提示词；最终摄影实施交给 `$craft-cinematic-image-prompts`。

## 必读参考

- 所有镜头组与四宫格任务读取 [references/storyboard-grammar.md](references/storyboard-grammar.md)。
- 涉及打斗、追逐、多人空间、越轴、蒙太奇或复杂连续性时读取 [references/continuity-and-editing.md](references/continuity-and-editing.md)。

## 输入契约

优先接收：

- `SCRIPT_PACKET`：场景目标、人物选择、信息变化、情绪转折。
- `TIMING_MAP`：时间范围、对白、声音和动作峰值。
- `ASSET_REGISTRY`：人物、实体、环境、道具和状态版本。
- `ACTION_PACKET`：动作轴、身体路径、接触、受力、起止状态。

如果只有普通剧本文本，先提取最小场景卡和连续性假设；如果动作复杂而没有动作包，先调用 `$craft-cinematic-action-design`，不要用快速切镜隐藏身体逻辑。

## 工作流程

### 1. 定义场景的观众任务

每个镜头组先回答：

- 观众进入时知道什么，离开时新知道或误判什么？
- 这一段优先属于谁的经验？
- 观众应该靠近、旁观、窥视、追随、审视还是暂时迷失？
- 哪个决定、动作或信息必须拥有最清楚的一镜？

没有信息变化、关系变化或动作必要性的镜头，删除或合并。

### 2. 建立空间与轴线

在拆镜头前画内部俯视图：入口、出口、角色起点/终点、障碍、高差、光源、威胁和关键道具。建立主要视线轴和运动轴，记录每个角色的屏幕方向。

遵循：

- 同一连续动作中，屏幕方向必须稳定。
- 需要越轴时，使用可见穿轴移动、中性轴上镜头、明确空间重建或有意义的跳变。
- 人物出画和下一镜入画方向相匹配，除非剧情要制造断裂。
- 视线匹配由真实人物位置决定，不能只让两张脸朝相反方向。

### 3. 决定镜头数量与时长

镜头数由信息和动作相位决定，不由“四宫格”强迫。一个四宫格代表最多四个连续镜头；场景不足四镜时保留空格或缩减版式，超过四镜时拆成多个有编号的四宫格。

秒级设计写镜头起止时间和内部动作相位，不每秒切镜。对白时长、反应时间、阅读复杂度、运动速度和 VFX 峰值共同决定镜头长度。

### 4. 建立镜头因果

每个镜头声明：

- 镜头为何从上一镜切入。
- 主要主体、动作和第一阅读层级。
- 摄影机相对空间位置、观看权限和轴线侧。
- 景别、角度、透视倾向、是否运动及运动动机。
- 必须看清和故意隐藏的信息。
- 镜头在哪个眼神、动作、声音或信息点切出。
- 下一镜继承的人物、道具、损伤、方向、天气、VFX 和情绪状态。

景别变化要有信息或情感理由。不要机械使用“大全中近特”，也不要用随机广角、倾斜机位和无人机镜头冒充电影感。

### 5. 整合动作

从 `ACTION_PACKET` 选择最有叙事价值的相位，不必一格对应一镜。一个长镜头可以容纳多个动作相位，一次接触也可能需要动作前视线、接触宽镜和后果近景。

优先确保：

- 预备方向、支撑脚和道具握持可读。
- 接触点至少在一个镜头中没有被遮挡。
- 反作用、失衡和后果不被过早剪掉。
- 摄影机运动不与主体运动无意义地互相抵消。

### 6. 建立影片摄影语法接口

分镜先锁定摄影语法的结构层：镜头家族、摄影距离原则、运动纪律、构图/遮挡、暗部权限和色彩叙事。具体摄影机型号、光圈、快门、灯具和最终 VFX 参数交给 `$craft-cinematic-image-prompts`。

AI 漫剧同样需要稳定语法，但可使用 `cinematic-ai-comic` profile：锁定线条/渲染密度、角色比例、背景细节级别、动作夸张范围和镜头连续性；不要自动加入真人皮肤语言。

### 7. 输出四宫格与独立镜头

默认生成两套：

- **四宫格审阅板**：2×2 或横向四格，统一画幅、面板尺寸、角色比例和世界状态，用于检查节奏与连续性。
- **四张独立分镜提示词**：每镜单独生成，重复必要的资产和连续性锚点，获得更可靠的构图与身份。

四宫格中的文字、镜号、时间码和箭头建议后期排版；不要依赖图像模型准确生成标签。

## STORYBOARD_PACKET

每个包包含统一契约字段，以及：

- `sequence_id`、`scene_id`、`beat_refs`、`timing_refs`、`time_range`
- `audience_task`、`information_change`
- `axis_map`、`screen_direction`、`spatial_map`
- `shot_ids`、`cut_logic`、`sound_bridge`
- `asset_refs`、`action_refs`
- `cinematography_profile`
- `continuity_in`、`continuity_out`

单镜头使用稳定 `SH001` ID，并记录：

`start/end/duration → story_function → subject/action → camera_position → shot_size/angle → axis_side → composition/occlusion → focus_of_attention → camera_motion → light/color intent → sound → cut_in/cut_out → continuity`

## 默认输出

### 导演判断与观众路径

说明本段以谁为中心、观众何时获得什么、为何采用当前镜头数量和剪辑节奏。

### 空间与轴线图

用简短文字或 ASCII 说明人物、入口、出口、关键物体、主轴和屏幕方向。

### 秒级镜头表

逐镜列出 ID、时间码、功能、机位、景别、动作、声音、切入/切出和连续性。

### 四张独立分镜提示词

每镜输出一条平台中立的英文提示词。强调构图、空间、动作、表演和可读性，避免在草图阶段堆满最终纹理和后期参数。

### 四宫格审阅提示词

输出一个 2×2 或横向四格的英文联系表提示词，明确阅读顺序和共享状态；准确标签留给后期。

### 连续性审查

检查轴线、视线、出入画、动作匹配、资产状态、天气、光源、色彩、声音桥和 VFX 阶段。

### 最终镜头交接

将 `STORYBOARD_PACKET`、资产引用和动作引用交给 `$craft-cinematic-image-prompts`。只有在这一阶段之后才写最终逐镜摄影提示词。

## 边界

- 不把四宫格限制反向变成固定四镜结构。
- 不把分镜画成海报、角色设定图或四张同角度近景。
- 不用快速切镜掩盖动作、空间或因果不清。
- 不用焦段型号和灯具清单替代摄影机立场；具体器材留给最终镜头。
- 不在下游镜头中静默改写剧本结果、资产 DNA 或动作接触关系。
- 不让每一镜都追求最大视觉冲击；建立强弱、留白、反应和余波。
