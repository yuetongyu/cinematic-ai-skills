# 神话影视改编工作表

使用这份工作表把检索结果交给剧本或视觉资产流程。每次只填与当前任务相关的部分，不要把全部神话资料搬进成稿。

## 1. 事实底稿

- 文化母体：
- 地域与时代：
- 使用的具体版本/传统：
- 数据集命中：实体、关系、事件、器物、术法：
- 已核验的一手/学术来源：
- 版本差异与不确定性：
- 活态信仰、族群或仪式敏感点：

## 2. 结构转译

- 保留的核心命题：例如誓约不能撤销、死亡需要被护送、秩序以牺牲维持。
- 项目改编的当代压力：把神话问题放进谁的生活、制度或关系里？
- 主角欲望：他具体要改变什么？
- 对手或本土权威：谁从现状获益？谁有权解释传统？
- 关系反转：亲缘、师徒、敌对、婚姻、债务或神人关系怎样改写？
- 不可逆选择：主角必须亲自做什么，且不能靠解释撤销？
- 代价：身体、寿命、记忆、名誉、共同体、土地或神圣关系失去什么？
- 下一层悬念：本集解决后，哪条秩序变得更危险？

## 3. 视觉与动作转译

- 形状母语：本传统最容易被辨认的轮廓、空间和构图关系。
- 材料：器物、衣料、建筑、皮肤、金属、木、石、火、水或声音的真实质感。
- 关键动作：祭、舞、献、誓、渡、封、追、斩、变形、护送或称量。
- 关键声音：鼓、歌、钟、诵、风、潮、动物声或人群回应。
- 边界表现：什么门、桥、墓、海、天、树、城墙、名字或身体不能随意越过？
- 环境后果：天气、地面、影子、动物、器物和群众如何对行动作出反应？
- 禁用混搭：哪些现代奇幻视觉会破坏这一传统的辨识度？

调用图像 skill 时，把以上内容分成“传统事实/项目改编/摄影过程/负面控制”四层；不要用 `cinematic`、`epic`、`8K` 代替文化和摄影决策。

## 4. 跨谱系接口

只有当故事确实需要不同传统相遇时，才建立接口：

1. 先写清两套秩序各自认为什么是合法的。
2. 指定翻译媒介：信物、语言、婚姻、贸易、战争、航路、梦、祭仪或共同灾害。
3. 写出不可翻译的部分，以及谁承担翻译失败的代价。
4. 保留本土权威的反应，不能让外来主角自动成为最高解释者。
5. 禁止用“全球神力”“万能法典”“共同能量颜色”抹平差异。
