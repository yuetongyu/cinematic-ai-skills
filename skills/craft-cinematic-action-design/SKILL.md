# 世界级电影动作指导

## 目标

把“打一场”“挥刀”“施法”“抱住她”等抽象动作写成演员、动画、姿态控制和图像/视频模型都能理解的时空因果。动作首先揭示人物欲望、关系和代价，其次才展示技巧；每个漂亮姿态都必须来自前一拍的力，并能进入下一拍。

本 skill 不决定故事结局，不设计角色外观，也不代替摄影分镜。输入不足时可做可撤回假设，但不得擅自改变角色能力、道具结构、空间尺度或剧本结果。

## 必读参考

- 设计任何四宫格、打斗、追逐或复杂身体交互时读取 [references/action-grammar.md](references/action-grammar.md)。
- 涉及多人、武器、非人身体、超自然力量、布料/头发或 VFX 连续性时读取 [references/action-continuity.md](references/action-continuity.md)。

## 输入契约

优先接收：

- `SCRIPT_PACKET`：场景、节拍、人物目标、动作结果、情绪转折。
- `TIMING_MAP`：动作可用时长、峰值时间和剪辑边界。
- `ASSET_REGISTRY`：身体比例、服装、配饰、道具、关节/功能限制。
- 空间资料：地面、障碍、入口、出口、高差、可破坏物和环境条件。

若通过 `$orchestrate-ai-drama-production` 调用，输出符合统一契约的 `ACTION_PACKET`，保留上游 block ID 和 revision。

## 工作流程

### 1. 识别动作的戏剧功能

先回答：

- 谁想通过动作改变什么？
- 对方在阻止、误解、引诱、保护还是承受？
- 这一段结束后，关系、能力、身体或环境有什么不可逆变化？
- 观众应该感到力量、危险、亲密、笨拙、犹豫还是代价中的哪一种？

不要用技巧复杂度替代戏剧升级。动作升级来自退路减少、身体代价增加、关系越线或规则被迫暴露。

### 2. 建立动作约束

锁定人物/实体的体型、重心高度、惯用侧、伤病、服装活动量、鞋底/地面摩擦、道具重量和握持方式。锁定场景坐标、人物起止位置、屏幕方向和障碍物。

超自然能力也必须有可读机制：由身体、器物、声音、环境还是空间规则触发；对施术者、目标和环境分别产生什么力与后果。

### 3. 写动作因果链

使用：

`意图 → 预备 → 发力源 → 动力链 → 位移/轨迹 → 接触 → 力传递 → 失衡/抵抗 → 回收 → 残留后果`

每个动作至少说明：

- 支撑脚或支撑面、骨盆和躯干方向。
- 发力从哪里开始，经过哪些主要关节。
- 手、脚、武器或身体的三维路径。
- 谁主动接触谁，接触在何处、以什么角度发生。
- 受力对象如何变形、位移、旋转或吸收力量。
- 头发、服装、悬挂配饰和碎屑如何晚于主体运动。
- 动作结束后谁失去平衡、呼吸、视线、武器或空间控制。

### 4. 选择四个关键相位

默认四宫格不是平均抽帧，而是四个有因果功能的关键姿态：

1. **Panel A / 意图与预备**：目标、距离、重心与潜在路径可读。
2. **Panel B / 发动与承诺**：力量已离开安全位置，动作不可轻易撤回。
3. **Panel C / 接触与峰值**：接触点、力方向、VFX 峰值和关系变化清楚。
4. **Panel D / 回收与后果**：惯性、伤害、环境反馈及下一动作入口可读。

没有接触的动作按功能替换，例如追逐使用“发现 → 加速 → 越障 → 失衡/逃脱”，亲密动作使用“靠近 → 停顿 → 接触/拒绝 → 关系余波”。不得机械套用拳击模板。

### 5. 保持连续性

四格必须保持：

- 同一角色/实体身份、服装、配饰、伤势和道具状态。
- 同一空间坐标、地面、高差、风向、重力和光源方向。
- 明确的屏幕方向与动作轴；越轴必须先用中性镜头或可见移动建立。
- 动作路径连续，接触之后不能回到接触之前的状态。
- VFX 源、流向、碰撞、沉积和耗散随相位推进。
- 破坏、灰尘、血迹、湿润和道具变形只增加或合理转移，不自动复原。

### 6. 生成 AI 可理解的提示词

提示词使用具体身体关系，不写“dynamic pose”“epic fight”代替动作。对每格明确：

- 人物和物体在画面中的相对坐标。
- 面朝方向、视线对象、支撑脚、膝髋肩关系和身体重心。
- 动作轨迹、接触点、受力方向和运动模糊范围。
- 道具握持、服装/头发延迟、环境反馈和 VFX 当前相位。
- 不可变资产 DNA 与只在该格变化的状态。

默认输出四张独立提示词，供高质量生成；另输出一条横向或 2×2 四宫格联系表提示词用于动作审阅。联系表不依赖模型生成准确文字，面板字母和时间码建议后期排版。

## ACTION_PACKET

字段：`packet_type`、`block_id`、`revision`、`depends_on`、`scene_id`、`beat_id`、`timing_refs`、`time_range`、`dramatic_function`、`participants`、`asset_refs`、`space_axis`、`screen_direction`、`start_state`、`action_path`、`contact_and_force`、`end_state`、`environment_response`、`vfx_phase`、`continuity_in`、`continuity_out`、`assumptions`、`change_log`。

## 默认输出

### 动作导演判断

用 3–6 条说明动作为什么这样设计、人物关系如何进入身体、真实风险是什么。

### 动作技术卡

列出起止状态、坐标/轴线、发力链、轨迹、接触、受力、道具与环境反馈。

### 四宫格相位表

每格给出时间范围、剧情功能、关键姿态、运动方向、连续性输入/输出。

### 四张独立提示词

每格一条可复制英文提示词，重复必要资产 DNA 和空间约束，只改变该相位允许变化的动作状态。

### 四宫格审阅提示词

输出一条 2×2 或横向四格的英文联系表提示词；保持格子尺寸稳定、同一人物比例和空间坐标。准确标签留给后期。

### 动作连续性与负面控制

列出最可能破坏动作的错误：左右互换、支撑脚漂移、武器换手、接触穿模、无重量、错误关节、轴线跳变、衣物提前运动、受损状态复原、VFX 相位倒退等。

### 分镜交接

给 `$craft-cinematic-storyboards` 提供 `ACTION_PACKET`。动作包定义身体和空间事实，不预设最终景别、焦段或剪辑。

## 边界

- 不把武术流派、军警程序、仪式或残障身体动作写成未经核验的刻板印象。
- 不用不可拍摄的解剖扭曲换取“冲击力”。
- 不把所有角色设计成同一速度、同一重心和同一表演强度。
- 不把四宫格四张图写成四个互不相干的海报。
- 不让摄影机运动掩盖动作逻辑；摄影决策交给分镜和镜头 skill。
