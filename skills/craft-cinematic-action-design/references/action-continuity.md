## 连续性状态

动作开始前建立状态向量：

`位置 + 朝向 + 姿态 + 支撑 + 握持 + 伤势 + 装备 + 环境 + VFX`

每个相位只通过可解释事件修改状态。接触、破坏、脱手、受伤、湿润和污染不能在后续格无因复原。

## 屏幕方向与轴线

- 用角色 A 到角色 B 或主要移动路径建立动作轴。
- 记录 A、B 在屏幕左右及各自面向。
- 同一动作链中摄影机保持在轴线同侧。
- 若动作本身穿过轴线，先让观众看到穿越路径。
- 动作四宫格的机位以清楚比较姿态为主，不追求每格全新角度。

## 武器和道具

锁定：

- 惯用手、辅助手、握持位置和刃/枪口方向。
- 道具长度、质量感、重心和碰撞边界。
- 挥动、后坐、绳索张力、弹性或流体残留。
- 脱手、断裂、弹匣、开关、鞘、绳链和附件状态。

道具通过身体产生力，也反过来改变身体。长重武器需要更早预备、更大制动空间和更明显的反作用。

## 多人动作

- 为每人指定独立目标、路径、节奏和反应。
- 避免所有人同时完成动作峰值。
- 接触链按因果排序，区分主作用和二次碰撞。
- 群体运动保留通道、盲区和碰撞风险，不排成平面队列。
- 反应必须匹配看到、听到或被触及的时机。

## 超自然与 VFX

将 VFX 视为力量载体：

`触发 → 源 → 传播 → 命中/绕流 → 光照/热/压力 → 沉积 → 耗散`

每格标明当前阶段。能量不能在接触前产生命中破坏，也不能在峰值后立即完全消失。施术者身体要承受反力、热、呼吸或注意力成本。

## 四宫格审查

- 是否只生成一张 16:9 图片，并明确使用 2×2 等尺寸面板？
- 身份、比例、服装和配饰是否稳定？
- 左右手、武器方向和屏幕方向是否稳定？
- 重心是否有支撑或明确失衡？
- Panel B 是否能自然进入 Panel C？
- 接触双方是否在同一空间且有反作用？
- 衣物、头发和碎屑是否晚于主体？
- Panel D 是否保留接触后的伤害、位移和环境变化？
- VFX 是否沿时间正向发展？
- 四格是否解释一个动作，而不是展示四个招式？
