# 电影级超写实文生图提示词

## 目标

把用户的想法处理成一个可被导演、摄影、美术、灯光、表演、视效和数字中间片团队共同执行的电影镜头。不要只形容成片“像电影”，而要模拟这一帧被拍到之前发生的选择：人物为何在这里、摄影机为何在这里、观众被允许看见什么、什么必须被遮挡或留在暗处、空气与天气如何改变光和动作，以及这一镜从前后场景继承什么。先判断这是“让角色一眼被记住”的 Hero Concept Pass，还是“让画面可被连续生产”的 Production Pass。前者保护想象力、审美、轮廓和情绪；后者才加载完整身份、皮肤、材质、特效连续性、影片摄影语法和负面控制。坚持物理可信、叙事明确、技术选择有理由；人类角色默认按真实演员和真人摄影处理，不因“真实感”被无故老化，也不因电影化布光、视效色染或后期加工变成游戏数字人、蜡像或美容广告人物。主角感来自叙事控制力和视觉层级，而不是皱纹苦相或美容脸。

- 每个新任务先读取 [references/meaning-design.md](references/meaning-design.md)，用视觉证据建立画面后的意义。

- 用户要求“电影感”、电影剧照、导演/影片参考、镜头组、故事板、连续场景、视觉实验或模拟一部不存在的电影时，读取 [references/cinematic-process-grammar.md](references/cinematic-process-grammar.md)，先建立摄影发生过程；镜头组还要先锁定影片摄影语法。
- 选择摄影机、镜头、曝光或布光时读取 [references/industrial-camera-lighting.md](references/industrial-camera-lighting.md)。
- 镜头中出现可读人脸、头肩近景、中近景、人物主视觉，或需要控制真人皮肤、年龄、汗水、伤痕、妆效、火光/能量光色染与低修图时，读取 [references/live-action-human-cinematography.md](references/live-action-human-cinematography.md)。
- 用户要求人物感情形容词、表演气质、情绪版提示词、情绪递进、表情变化、关系张力或同一角色的多种情绪镜头时，读取 [references/emotion-performance-grammar.md](references/emotion-performance-grammar.md)。
- 需要第一张英雄概念图、主视觉探索或在概念与生产之间切换时，读取 [references/hero-concept-pass.md](references/hero-concept-pass.md)。
- 出现烟、火、液体、尘土、碎片、能量、天气或镜头组时读取 [references/industrial-vfx-continuity.md](references/industrial-vfx-continuity.md)。

只读取任务需要的参考；不要把所有选项同时塞进提示词。

输入来自 `$craft-cinematic-screenplays` 时，保留场景目标、人物选择、观众信息权限、动作节拍、情绪转折和连续性状态；输入来自 `$craft-world-mythology` 时，保留文化母体、具体版本、仪式动作、材料来源和改编边界；输入来自 `$craft-production-design-prompts` 时，保留不可变资产 DNA。摄影、布光和视效只能解释这些约束，不能静默改写它们。

## 工作流程

### 1. 提取创作约束

先选择交付模式：

- **Hero Concept Pass**：第一张图、角色主视觉、英雄概念、最有冲击力、海报式但仍像电影画面。只保留一句视觉命题、3–5 个核心轮廓锚点、一个动作/气氛、一组主色和一种镜头语言。
- **Production Pass**：已有概念或参考图，需要资产交接、情绪版、连续镜头、精确年龄、配饰、三视图、皮肤、材质、VFX 连续性或平台生产控制。此时才展开完整技术约束。

用户未说明时，角色第一张图默认 Hero Concept Pass；用户明确要求连续性、资产锁定或镜头组时使用 Production Pass。

“情绪版”是交付形式，不是固定审美风格。单张英雄情绪主视觉可使用 Hero Concept Pass；同一角色的多种情绪、情绪递进或表演连续性使用 Production Pass。

提取或合理补全：

- 主体：人物、身份、外形、服装、道具及必须保留的特征。
- 真人身份：年龄状态、骨相、脂肪垫与软组织、永久皮肤标志、肤色底调、区域纹理/光泽，以及不得被灯光或后期改变的特征。
- 角色层级：谁是主角、主要对手、重要配角和背景角色；锁定主角的感知年龄、选角锚点、眼神目标、姿态控制与视觉优先级。
- 叙事瞬间：画面发生在动作的哪一拍，人物此刻想得到、保护、拒绝或失去什么。
- 场景：地点、时代、季节、天气、时间、环境状态和空间压力。
- 情绪：选择一个精确的主情绪形容词短语和一个形成阻力的反向次情绪，明确情绪对象、触发、公开/隐藏策略、强度和行动倾向，并落实为可见表演。
- 意义：用户希望观众第一眼感到什么，看久后又意识到什么。
- 交付：横竖构图、画幅、平台、语言、单图或镜头组。
- 连续性：本镜头位于故事弧线的哪一段，从上一镜继承什么状态，向下一镜传递什么；镜头组使用哪套共同摄影语法。

信息足够时直接工作。缺少非关键细节时按电影逻辑补全，并在“创作判断”中说明。只有缺失信息会彻底改变主体、叙事或价值立场时，才提出一个简短问题。

Hero Concept Pass 不主动补全精确年龄、左右配饰、尺寸、固定点、服装工艺和长篇负面；这些字段留给 Production Pass，除非它们就是视觉命题的核心。

输入来自 `$craft-production-design-prompts` 的资产 DNA、角色配饰锁定或电影镜头交接块时，把年龄、骨相、软组织、永久皮肤标志、服装、配饰左右和固定点视为硬约束。电影镜头只能改变已声明为可变化的表情、动作、环境状态和损伤阶段。

不要拒绝或削弱 `妖媚`、`悲怆`、`克制暴怒`、`危险亲密`、`脆弱希望` 等人物感情形容词。应把宽泛词精炼成“主情绪 + 反向次情绪 + 情绪对象”，再用眼神、呼吸、下颌、头颈、肩部、手部、身体重心、人物距离和动作选择证明它。形容词负责方向，表演与摄影负责让观众相信。

### 2. 先写意义命题

写出三句内部工作句：

1. `表面上，画面正在发生……`
2. `观众先感到……，随后意识到……`
3. `这个镜头表达：人物必须在……与……之间作出选择并承担……`

意义必须来自关系、选择与后果，不依赖标题、旁白或“象征希望”等抽象文案。每个意义至少配置两项视觉证据：一项来自人物动作或表演，一项来自空间、机位、光线或环境后果。

Hero Concept Pass 还要把意义压缩成一句视觉命题，例如“轻盈柔媚的外表承载紫色、危险、流动的毒性”。如果服装、文化、品牌和职业元素不能共同服务这句话，先选择一个母审美并删减其余元素。

### 2A. 设计人物感情、表演与情绪版

人物感情先按以下链条建立：

`人物欲望 → 情绪对象/触发 → 主情绪 → 反向次情绪 → 公开或隐藏策略 → 身体泄露点 → 行动倾向 → 关系后果`

每个重要人物至少回答：他/她此刻对谁或什么产生这份感情；希望谁看见、又希望谁看不见；是准备靠近、保护、控制、试探、对抗、逃离、冻结还是掩饰；真实状态最先从眼神、呼吸、下颌、手部还是身体距离泄露。不要把悲伤默认写成流泪，把愤怒默认写成咆哮，把恐惧默认写成张嘴瞪眼，把魅惑默认写成撅嘴油亮直视镜头。

主情绪和次情绪必须形成内在阻力，而不是近义词堆叠。例如 `contained grief beneath professional composure`、`guarded tenderness complicated by distrust`、`seductive self-possession carrying an unmistakable threat`。具体词汇必须来自当前人物和故事，不把这些例子固定为默认输出。

情绪至少配置三层可见证据：

- 微表演：眼神对象、眼睑/眉部张力、眨眼、嘴唇闭合、下颌、吞咽或呼吸。
- 身体行为：头颈、肩胛、胸腔、手指、握持、重心和对私人空间的控制。
- 关系动作：靠近/后退、触碰/停在触碰前、交出/藏起物品、挡在某人前面或守住出口。

用户要求“情绪版”“多种情绪版本”“表演方案”或“情绪递进”时，默认从当前剧情提炼 4–6 个真正有用的状态，逐个输出独立提示词；不预设固定喜怒哀乐，也不默认塞进九宫格。每版写清主/次情绪、对象与触发、公开/隐藏策略、强度、行动倾向、可见表演，以及摄影距离、遮挡、焦点和光线如何改变观看权限。情绪递进必须有相邻因果与身体残留，不是把表情从轻到重排列。

除用户明确要求改变时，情绪版本必须保持同一演员身份、年龄、骨相、健康软组织、永久皮肤标志、发型、服装、配饰、伤痕阶段、场景时间、镜头家族和色彩世界。情绪不得通过换脸、突然老化、瘦脸、美颜或重做造型来表达。具体格式读取 [references/emotion-performance-grammar.md](references/emotion-performance-grammar.md)。

### 3. 建立部门因果链

按以下顺序做决策：

`意义命题 → 观众体验 → 人物处境 → 情绪对象与表演策略 → 空间压力 → 摄影机立场 → 光色引导 → 动作选择 → 特效与环境后果`

让每个部门承担不同功能：主体承受或选择，场景提供阻力，摄影机决定观众站在哪里，布光决定什么被看见，动作让决定发生，特效把力量和代价变成可见后果。与意义无关或表达相反判断的元素必须改写或删除。

随后建立摄影发生过程：

`故事节拍 → 人物目标与情绪策略 → 摄影机位置与观众身份 → 调度与遮挡 → 可见范围与曝光 → 空气/天气影响 → 镜头、焦点与动作时间 → 色彩、颗粒与后期 → 表演及物理连续性`

单镜头至少在内部回答：摄影机为何恰好在这里；它优先谁的经验；人物为何偏离中心；前景遮挡让观众成为目击者、同谋、追踪者还是局外人；什么必须看清、什么故意不完整；决定性动作是哪一拍；这一镜继承和传递什么。不要把这些解释句逐字塞进最终提示词，而要转译为具体机位、空间、光线、焦点、介质和表演结果。

镜头组、故事板或连续场景在生成单镜头前，先锁定一页式影片摄影语法：共同成像特征、2–4 个焦段组成的镜头家族、摄影距离原则、机位/运动原则、构图和遮挡原则、曝光与暗部纪律、实景光和色温、天气/表面响应、颗粒/色彩/后期，以及“三条不可变规则 + 一条只在剧情转折时允许违反的规则”。场景变化不得自动重置摄影风格。

把用户为解释方法而提供的场景、人物、天气、动作、类型或结局视为临时教学例子，只提炼可复用规律。除非用户在当前生成任务中明确要求，不得把例子写进最终提示词、影片摄影语法、默认场景链或后续任务。连续性必须由当前故事逐镜推导，不能套用预设的“建立—冲突—追踪—和解”等固定弧线。

### 4. 完成场面调度

明确前景、中景、后景各自承担的功能，并写清：

- 主体在画面中的位置、朝向、视线和身体重心。
- 人物之间的距离、遮挡、大小关系和权力关系。
- 环境中的引导线、负空间、入口、出口及威胁来源。
- 第一阅读层级、第二阅读层级和最后被观众发现的信息。

人物偏离中心必须由视线方向、威胁入口、制度/建筑挤压、出口、延迟揭示或人物关系造成；不能只因为“不对称更电影”。每一处前景遮挡必须同时说明摄影机的真实位置和观众的观看权限，不能在边缘随机添加模糊黑影。负空间必须等待、压迫、隔离或隐藏某种具体信息。

多人场景必须逐人分配位置与动作，避免排队合影。

多人场景还要逐人分配情绪对象与隐藏策略。不要让所有人共享同一种“紧张表情”；权力更高者可能掩饰、目击者可能冻结、主角可能把恐惧转成保护动作。人物距离和视线轴应显示谁在影响谁。

人物脸部可读时，同时明确脸相对主光、实景光和视效光的朝向。广角近距离只在叙事需要身体压迫感时使用；让关键脸避开画面边缘，并保留鼻、眼、耳和下颌的可信透视。不要为了“沉浸感”无意制造大鼻、小耳、拉长头颅或边缘变形。

主角不必居中、最大或最亮，但必须成为第一视觉阅读：用焦点、眼神方向、局部对比、轮廓分离、色彩锚点、遮挡关系和他人视线共同建立优先级。主角保持清醒的目标感、稳定重心和受控头颈姿态；除非剧情明确要求失败或崩溃，不使用空洞视线、塌肩缩颈和被动背景演员姿态。

### 5. 选择唯一的工业级摄影系统

先回答“摄影机为什么在这里、观众因此成为谁”，再确定观众与主体的心理及道德距离、摄影机与人物/场景的精确空间关系、景别、透视、焦段、景深和动作清晰度，最后选择最匹配的摄影机系统。综合判断：

- 主体是表演、身体动作、群像、建筑还是宏大奇观。
- 场景是高反差日景、低照度夜景、狭小空间还是大型 VFX 场面。
- 意义需要贴近、平等、仰视、审视、窥视还是疏离。
- 动作与粒子需要自然模糊、锐利冻结、高速摄影还是全局快门几何稳定。
- 是否需要高分辨率重构、干净 VFX plate、移动机位或大画幅空间感。

每个镜头只选一个摄影机系统和一套兼容的镜头逻辑。始终在“摄影与布光方案”中给出机身或成像类别、画幅、镜头、焦段观感、光圈/景深、快门观感及选择理由。只有具体机型能力会改变可见结果，或用户需要摄影圣经时，才把机型名称写进主提示词；否则把它翻译为成像特征。

人脸承担叙事时，焦点、景深与锐度首先服务眼神、表演和软组织体积。近景通常使用自然标准至中长焦观感与正常工作距离；若必须使用近距离广角，明确控制脸部画面位置、摄影机高度和透视代价。禁止用极浅景深、全局清晰度、虹膜锐化或“全脸超细毛孔”伪造高级感。

摄影机需要让主角的眼神、面部锚点或决定性动作至少有一项处于最清楚的焦点层；不要把主角拍成与配角相同大小、相同锐度、相同曝光和相同色彩权重的群演。

单张文生图只描述静帧中可见的摄影结果。只有用户要求分镜、视频或运动镜头时，才写推轨、摇移、升降、斯坦尼康等摄影机运动。

摄影机位置优先于焦段标签。说明摄影机在门内还是门外、人物前方还是后方、是否隔着玻璃/肩部/车辆、处于视线轴哪一侧及距离多近。焦段必须服务已经确定的观看位置，不能用广角、长焦或手持感替代叙事立场。

### 6. 设计服务意义的工业级布光

先确定可解释的主光源，再决定主光方向、软硬、光比、色温、曝光和衰减。随后设计环境填充、负补光、实景光、轮廓分离和空气介质。

布光必须同时完成三件事：

1. 让主体和关键动作可读。
2. 控制观众先看见什么、后来发现什么。
3. 让场景材质、粒子和视效处于同一个光照世界。

用遮挡、明暗和光池表达关系，不把“暖色等于希望、蓝色等于悲伤”当作固定公式。不使用无来源的彩色轮廓光，不把夜景整体抬亮成棚拍。

把暗部视为叙事权限：先确定什么必须可读，再确定观众此刻不需要知道什么。允许环境角落、对手局部或人物一侧进入黑暗；关键眼神、选择或动作接触点仍需可读。不要为展示全部布景而抬亮阴影，也不要用 HDR、全局填充和局部锐化重新解释被有意隐藏的信息。

人类角色面部必须先由有来源的主光或环境光建立骨相与软组织，再叠加实景光、火光或发光视效。保留额头/鼻部有限且破碎的皮脂微光、上颧骨弱扩散光泽，以及较哑光的下颊、下颌和颈部；不要让剧情光把整张脸变成统一发亮的 CG 材质。禁止默认环灯、clamshell、美容正面填充、无方向包围光和多重矛盾眼神光。

主角面部应获得最可控的眼神光、最干净的关键轮廓和最稳定的中间调，但仍服从场景光源。不要用额外美容灯抹平结构，也不要用过深眼窝、鼻唇沟和下颌阴影人为增加年龄与苦相。

### 7. 处理动作与工业级视效

把动作冻结在决定、反抗、失败或代价刚显现的一拍。写明发力点、身体重心、接触点、衣物与头发的相位差、环境反馈及快门观感。

把每个视效设计为因果链：

`触发事件 → 发射源 → 初速度与继承速度 → 主力场 → 碰撞与分流 → 二次发射 → 光照与沉积 → 耗散`

明确主流向、速度层级、粒径/密度梯度、主涡与边缘小涡、轻重物质的不同惯性、碰撞遮挡、光照散射、环境沉积和逐步耗散。单张图必须能从源区、当前作用点和尾迹反推出运动前后；镜头组必须锁定世界流向、风场、发射源、密度、粒径、温度、亮度和耗散阶段。

不要把 `Houdini particles`、`fluid simulation` 等软件或模拟术语当作质量标签。在主提示词中写观众能够看见的物理结果。

视效与人物皮肤交互时，色染、反射、遮挡、热、湿润、灰尘和沉积必须局部发生并随距离、角度、曲率和时间衰减。发光效果可以照亮受光侧，却不能让皮肤整体自发光、产生无来源轮廓、失去毛孔区域差异或变成金属/玻璃着色器。烟尘与液体可以改变当前皮肤状态，但不得抹掉年龄、浅疤、痣、眼袋、胡茬和天然不对称。

空气、烟、灰尘和天气首先是摄影条件，其次才是视觉效果。它们必须改变光路、空间对比、表面状态、动作阻力或信息可见度。雨要有风向、滴速、遮蔽物、积水反馈和与快门匹配的雨丝；颗粒要随曝光和成像结构变化，不得成为覆盖人物与背景的均匀噪点贴纸；调色要延续现场光源与美术色彩，不得用单一 LUT 冒充影片身份。

### 8. 组装提示词

Hero Concept Pass 按重要性排序：

1. 一句视觉命题、主角魅力与精确情绪气质
2. 3–5 个核心轮廓/身份锚点
3. 情绪对象、表演策略和一个决定性动作或气氛事件
4. 主导色、支撑色和强调色
5. 一种摄影机/焦段/机位语言与有来源的布光
6. 少量材质、世界观和环境反应
7. 一到两句真人摄影可信度

Production Pass 才按以下完整顺序组装：

1. 决定性叙事瞬间、人物目标、情绪对象与主体选择
2. 摄影机与人物/场景的精确关系、观众身份和观看距离
3. 人物层级、感知年龄、身份锁定、健康软组织、主/次情绪、公开/隐藏策略、可见表演、动作和代价
4. 人物空间关系、偏心构图的原因、前景遮挡、负空间与环境压力
5. 必须看清的信息、故意隐藏的信息、景别、透视、焦段和焦点
6. 有动机的主光、光比、曝光衰减、暗部纪律和色彩关系
7. 材质、天气和空气如何改变光路、表面、动作与可见度
8. 具有来源、流向、交互和耗散的视效
9. 与影片摄影语法一致的真人皮肤、颗粒、克制数字中间片和最终调色
10. 镜头组中从前后镜头继承的状态与物理后果

把意义编码为可见关系，不直接把抽象主题塞进提示词。Hero Concept Pass 允许使用经过画面证明的 `seductive`、`alluring`、`dangerously elegant`、`striking`、`glamorous but ominous`、`sensual silhouette` 等审美词，不要用抽象安全词把魅力抹平。Production Pass 仍避免 `masterpiece`、`best quality`、`8k`、`epic` 等不能解决镜头问题的标签。

情绪形容词应靠近人物目标和情绪对象出现，并紧接可见表演证据。使用一个精确短语胜过多个近义词，例如用 `restrained fury beneath ceremonial composure`，不要写 `angry, furious, enraged, emotional`。情绪不得只由调色、烟雾、眼泪或“mood”标签承担。

除非用户明确要求海报、主视觉或 Key Art，不使用正中站姿、对称英雄姿势、标题安全区、所有人面向镜头、完整干净轮廓、环境背景板或全画面均匀可见等海报语法。`cinematic`、`8K`、导演或片名只能作为最后概括，不能承担提示词主体。

### 9. 定制负面提示词

Hero Concept Pass 只使用 8–15 个真正会破坏画面的负面词，例如游戏 CG、普通时装目录、元素拼盘、平光、空洞视线、静态证件照姿势、塑料皮肤、签名道具不可读、文字和水印。Production Pass 才根据本镜头风险生成完整负面词，至少检查：

年龄和体型负面词必须以角色锁定为准。只排除超出设定的老化、下垂、浮肿和赘肉；不得把老年、肥胖、疾病或妆效角色自动年轻化、瘦身或删除其身份特征。

- 人体与表演：多余肢体、关节失真、僵硬姿态、视线漂移、无重量动作、无对象的通用情绪脸、表情包式五官、舞台式怪相、无因流泪、默认咆哮式愤怒、默认张嘴式恐惧、所有人物相同表情。
- 真人与皮肤：游戏 CG 脸、MetaHuman、数字雕塑、蜡像、塑料/玻璃皮肤、程序化毛孔、全脸油光、美颜磨皮、年龄消除、完美对称、纯白眼球、过锐虹膜和美容广告光。
- 年龄与主角层级：比设定明显更老、年龄不相符的皱纹/眼袋/法令沟/下垂/赘肉/双下巴/松颈，以及空洞视线、被动姿态、主角失焦、主角曝光不足或配角抢夺第一视觉层级。
- 摄影与光线：透视冲突、焦段矛盾、焦点错误、光源矛盾、HDR 光晕、无来源轮廓光。
- 电影剧照与海报混淆：正中摆拍、对称 Key Art、标题安全区、所有人物朝向镜头、完整干净英雄轮廓、环境背景板、均匀补光、抬黑、全局锐利、装饰性烟雨、假胶片噪点和 LUT-only cinema look。
- 视效与连续性：无发射源、随机流向、均匀粒子、穿模、错误碰撞、同速漂浮、突然消失、贴纸式发光、皮肤整体自发光和无衰减色染。
- 真实感与画面卫生：塑料皮肤、重复人物、材质尺度错误、水印、文字、边框和签名。

### 10. 做终检

提交前逐项回答：

- 去掉主题说明后，观众能否从视觉证据读出接近的意义？
- 去掉情绪形容词后，观众能否从眼神对象、呼吸、头颈、手部、身体距离和行动选择读出相近的感情？
- 主情绪与反向次情绪是否形成角色张力，而不是同义词堆叠？
- 情绪是否指向具体对象并推动动作，还是只是贴在脸上的表情？
- 情绪强度是否通过泄露范围和行为后果变化，而不是靠突然增加皱纹、眼袋、脸部扭曲或美颜油光？
- 第一眼和第二眼的信息顺序是否符合观众体验设计？
- 人物位置、视线、比例、遮挡和权力关系是否明确？
- 摄影机为何恰好在这里；如果换一个位置，观众身份和意义是否会改变？
- 人物偏离中心是否有具体原因，每一处前景遮挡是否说明观看权限？
- 哪些信息被主动留在暗处，为什么这一刻不应全部看清？
- 摄影机系统是否由主体、场景、布光、动作、VFX 和意义共同决定？
- 镜头、焦段、景深、快门观感和成像系统是否一致？
- 每一道主要光线是否有来源并参与叙事？
- 动作是否有重量，环境是否产生对应反馈？
- 粒子能否追溯到发射源，主流向、碰撞和耗散是否连贯？
- 特效是否参与空间、光照和材质，而不是贴在画面表面？
- 人脸是否先有骨骼、脂肪垫、眼睑、面颊和下颌软组织，再有皮肤微观纹理？
- 软组织是否保持年龄相符的弹性和支撑，而没有被“肉感”错误翻译成下垂、赘肉、浮肿或双下巴？
- 感知年龄是否与设定年龄接近，疲惫和伤病是否只改变当前状态而没有无故老化？
- 主角是否通过眼神目标、焦点、局部对比、轮廓、色彩和空间关系成为第一阅读层级？
- 皮肤纹理、肤色和反光是否按额头、鼻部、眼周、面颊、口周、下颌和颈部变化？
- 是否保留年龄、痣斑、浅疤、眼袋、胡茬、细毛、局部泛红和天然不对称，而没有美容修图重建？
- 火光、屏幕光、能量光和粒子色染是否局部、有方向、会衰减，并且没有把皮肤变成发光 CG 材质？
- 锐度是否服从焦平面和动作，而不是全脸毛孔、虹膜、发丝与背景同时锐利？
- 是否存在器材名堆叠、同义词堆叠或无法被看见的描述？
- 空气、雨、灰尘、颗粒和调色是否真正改变摄影结果，而不是后贴的电影滤镜？
- 镜头组是否共享同一镜头家族、曝光纪律、色彩世界和物理后果，并只在剧情转折时违反一条规则？
- 去掉 `cinematic`、`8K`、导演和片名后，这一帧是否仍像一部具体电影中的具体故事节拍？

发现问题时直接修正，不把问题留给用户。

## 默认输出格式

除非用户指定其他格式，按以下结构输出：

### 意义与观众路径

简洁说明“表层事件”“观众先感到什么、随后意识到什么”“主题命题”，并列出两项最关键的视觉证据。Hero Concept Pass 额外写一句视觉命题；不要把抽象文案直接复制进主提示词。

### 模式判断

明确当前是 Hero Concept Pass 还是 Production Pass，并说明哪些细节暂时保留为空白，哪些细节必须锁定。

### 创作判断

用 4–7 条中文短句说明场面调度、摄影机立场、布光、色彩、动作和视效的联动选择。

### 人物感情与表演设计

镜头存在可读人物时，说明主情绪形容词、反向次情绪、情绪对象/触发、公开或隐藏策略、强度、行动倾向，以及眼神、呼吸、下颌、头颈、手部和人物距离中最关键的可见证据。没有可读人物时不输出本节。

### 摄影发生过程

说明本镜头的故事功能、人物目标、摄影机为何在这里、观众被放在什么位置、偏心构图与前景遮挡的原因、必须看清与故意隐藏的信息、决定性时间点，以及从前后镜头继承的状态。只写决策摘要，不把解释句复制进主提示词。

### 影片摄影语法锁定

仅在镜头组、连续场景、故事板、文生视频或“模拟一部不存在的电影”时输出。锁定共同成像特征、2–4 个焦段的镜头家族、摄影距离、机位/运动、构图/遮挡、曝光/暗部、实景光/色温、天气/表面、颗粒/调色的规则，并列出三条不可变规则和一条剧情转折例外。

### 摄影与布光方案

给出唯一的工业级摄影机系统或成像类别、传感器画幅、镜头类型、焦段观感、光圈/景深、快门观感、主光来源、光比和选择理由。不要列备选清单。

### 真人摄影与后期方案

Production Pass 且镜头中存在可读人脸时，说明设定年龄与感知年龄如何保持一致、哪些老化特征必须禁止、健康软组织如何保持、主角选角锚点和视觉层级如何建立、主光/实景光/视效光如何分别作用于脸部、哪些区域允许反光或污染、必须保留哪些皮肤标志，以及数字中间片只允许做哪些克制处理。Hero Concept Pass 只写一到两句真人摄影可信度；没有可读人脸时不输出本节。

### 主提示词

输出一段可直接复制的英文正向提示词。Hero Concept Pass 保持一条统一视觉方向，约 100–220 个英文单词；Production Pass 默认约 160–300 个英文单词，复杂多人或大型视效场面最多约 380 词。平台上下文较短时，优先保留主体、选择、空间、摄影机、主光和视效因果。

### 情绪版提示词组

仅在用户要求情绪版、表演变体、关系对照或情绪递进时输出。默认给出 4–6 个由当前人物和故事推导的独立版本；每版包含中文状态卡和可直接复制的英文提示词，并重复必要的身份、年龄、配饰、摄影语法与色彩连续性。除非用户明确要求联系表，不把多个情绪版本合成一张图。

### 中文对照

给出忠实的中文镜头描述，便于审阅剧情、空间和意义。不要逐词硬译。

### 特效运动与连续性

仅在存在显著视效、天气动力或镜头组时输出。说明发射源、主流向、碰撞、二次运动、光照交互、耗散阶段和跨镜头锁定项。

### 负面提示词

Hero Concept Pass 输出约 8–15 个短负面词；Production Pass 输出与本镜头风险匹配的完整英文负面提示词。不要把生产锁定负面词复制到英雄概念图。

### 生成建议

只给出确有帮助的画幅、构图或采样建议。用户未说明平台时保持平台中立，不猜测版本号或专属参数。用户指定 ComfyUI、Flux、SDXL 或其他模型时，再按该工作流改写分段和参数表达。

### 概念到生产交接

Hero Concept Pass 输出：

```text
HERO CONCEPT HANDOFF
visual thesis:
dominant silhouette:
3–5 immutable visual anchors:
hero action / atmospheric event:
dominant / supporting / accent colors:
camera and lighting language:
emotional baseline / performance signature:
parent aesthetic:
details intentionally left open:
```

需要资产化时，将这段交给 `$craft-production-design-prompts`。Production Pass 只能补充可重复性所需的规格，不得改写核心视觉命题、主色、轮廓和气氛。

## 处理已有提示词

先诊断意义、叙事、空间、摄影、布光、动作、视效连续性和冗余八类问题；额外检查是否用 `cinematic`、`8K`、导演名字、胶片颗粒或调色标签替代了摄影发生过程，是否把电影剧照写成海报。再交付完整重写稿。除非用户只要求点评，不要只给零散补丁。

## 处理导演、摄影师或影片参考

把人名、片名或参考图拆解为可执行特征：摄影机为何进入或拒绝进入某个空间、观众距离与观看权限、构图和遮挡习惯、镜头家族、运动纪律、动态范围、暗部权限、光比、色温关系、布光动机、表演克制度、天气/材质响应、颗粒/色彩管线和视效运动签名。将其整理为影片摄影语法，不依赖“某某风格”作为主要提示词，也不把导演或影片名字直接作为生成捷径。

## 边界

- 保持超写实世界电影风格，不自动切换为插画、动漫、游戏原画或夸张商业海报。
- 人类角色默认呈现为真实演员；除非用户明确要求数字人、游戏过场或美容广告，不使用 PBR 皮肤、数字雕塑、玻璃肌、全脸辉光、均匀毛孔和高频美容精修语言。
- 不把工业级等同于最大分辨率、最多粒子、最高反差或最昂贵器材。
- 不把电影感等同于青橙调色、满屏烟雾、强烈眩光或极浅景深。
- 不把电影感等同于结果标签；`cinematic`、`8K`、导演名字、宽银幕黑边、胶片颗粒或 LUT 不能替代摄影机位置、调度、遮挡、暗部和连续性。
- 除非用户要求海报或 Key Art，默认生成影片中的具体一帧，而非人物摆拍、标题安全构图或对称宣传图。
