## 1. 因果链

把每个效果设计成可追溯链条：

`触发事件 → 发射源 → 初速度与继承速度 → 主力场 → 涡量与阻力 → 碰撞与分流 → 二次发射 → 光照、遮挡与沉积 → 耗散`

- 指定可辨认的发射源。烟尘来自裂口、地面、排气口或燃烧面；火花来自金属碰撞或电气故障；碎片来自明确破碎体。
- 发射源在画外时，用来向、尾迹、阴影和环境反应交代位置。
- 指定初速度的主方向、速度级别和散布。移动主体产生的粒子继承主体速度；爆炸先接受径向冲量，再受重力、阻力和风场控制。
- 只设一个主导输运机制，再添加一个次级扰动。避免重力、风、吸力、冲击波和旋转场同时争夺方向。

## 2. 粒子与流体运动

### 流向与涡量

- 保留一个清晰主流向，让观众能追踪源区、作用点和尾迹。
- 使用大尺度涡旋决定整体卷动，只在剪切层和稀薄边缘出现小尺度卷须。
- 不用均匀随机噪声破坏主流向。
- 旋涡可以同时具有切向旋转和径向收束，但必须明确旋转方向、中心和主要趋势。

### 粒径、质量与阻力

- 细灰、薄雾和余烬快速贴合风场。
- 沙粒、液滴和重碎片保留惯性，沿更低、更短的抛物线下坠。
- 大碎片少、惯性强；小颗粒多、受风明显。
- 不让所有物质以相同速度、相同方向和相同幅度同步漂浮。

### 密度与耗散

- 源区或核心更密，边缘和尾迹逐渐变稀。
- 让速度衰减、结构拉长、团块破碎、边缘扩散、密度降低、温度下降、发光熄灭依次发生。
- 不让烟、火、能量或粒子在边界突然消失。
- 不把等大小、等间距、等亮度的粒子平均撒满画面。

### 碰撞与环境交互

- 让粒子在人物、地面、墙体和道具处反弹、滑移、卷起、飞溅、附着、破碎或沿表面分流。
- 让碰撞点出现方向变化、密度堆积、二次碎屑或液滴分裂。
- 让前景和主体真实遮挡效果；浓密介质遮暗后方，近处粒子可以局部遮住主体，但不能均匀蒙住整张图。
- 让效果吹动织物、头发和植被，卷起积尘，扰动水面，并留下焦痕、湿痕、沉积或碎片堆。

### 光照交互

- 让火焰、熔融物和能量体照亮邻近表面并随距离衰减。
- 让烟尘吸收、散射和切割光束，并产生体积阴影和密度变化。
- 让湿表面、金属、皮肤和玻璃出现合理反射与色染。
- 让亮度与现场曝光匹配，不让所有高亮核心无条件剪切成纯白。
- 人脸受视效光影响时，只让朝向发射源的额头、鼻梁、颧骨、眼睑、嘴唇或面颊曲面获得局部色染；鼻侧、眼窝、下颌和背光侧继续保留遮挡与暗部。
- 发光 VFX 不得把皮肤改造成均匀自发光、金属、玻璃或湿塑料材质；高光内部仍保留肤色、毛孔区域差异、细毛、皱纹和伤痕。
- 烟尘、灰烬、雨水、汗液和血液作为当前状态叠加在皮肤上，遵循重力、风、接触和蒸发/干燥；它们不能抹除年龄、永久标志和软组织结构。
- 强光源可造成局部过曝或轮廓消失，但范围必须由角度和曝光解释，不能给整个头部描一圈无来源发光边。

### 二次运动与相位差

- 让衣物、头发、悬挂物、积水、灰尘和轻碎屑在主冲击后滞后响应。
- 随后产生回摆、余震、尾流或逐步沉降。
- 不让所有元素同拍、同向、同幅度运动。

## 3. 单张静帧的连续运动

单张图冻结一个时间点，但必须保留动作前后的空间证据：

1. 前方尚未受扰的区域。
2. 当前接触、喷发、破裂或冲击点。
3. 后方已经形成的尾迹、沉积或余波。

让观众能够沿“发射源—运动主体/作用点—前缘—尾迹”反推出运动方向。

使用可见形状表达速度：压缩的冲击前缘、被拉长的尾迹、剪切卷边、抛物线碎片轨迹、迎风侧密集和背风侧稀薄。

让运动模糊服从局部速度与方向。保留面部、接触点或关键道具作为清晰锚点；只让高速前缘、肢体末端或近镜粒子出现受控拖影。

使用相位差显示动作顺序：主体已经改变姿态，衣物仍在滞后，细尘刚被卷起，重碎片已开始下坠，环境仍保留更早一拍的扰动痕迹。

## 4. 常见效果的物理签名

### 烟雾与尘土

- 烟受浮力与风场输运，核心较密，边缘形成卷须并逐渐扩散。
- 地面尘土先受冲击形成低矮前缘，细灰随后升高并随风拉成长尾。
- 体积必须遮挡和散射光线，不要表现成半透明贴纸。

### 火焰与余烬

- 明确燃料或燃烧表面；火焰向上卷动并受横向风场弯折。
- 核心更亮，边缘更冷；火焰向烟过渡，余烬随热流上升后逐渐变暗。
- 火光必须影响附近皮肤、金属、墙地和烟雾。

### 火花

- 只从金属撞击、电气故障或高温破裂点发射。
- 先高速发散，再受重力和阻力形成不同长度的弧线。
- 与表面碰撞后产生少量反弹和亮度衰减，不形成均匀放射烟花。

### 爆炸、冲击波与破碎

- 先显示核心或触发点，再显示径向冲量、重碎片低弧线、细尘高扩散和后续负压回卷。
- 破碎形状必须继承原结构、材料和受力方向。
- 让空气、衣物、水面和附近松动物产生相位不同的响应。

### 水、雨与液体

- 遵循重力、表面张力、撞击角度和主体继承速度。
- 飞溅具有冠状边缘、液膜、主液滴和更细二次雾滴；不同尺度运动不同。
- 让表面留下湿痕、波纹、反射和流淌路径。

### 能量与超自然效果

- 即使物理规则是虚构的，也要定义唯一传播介质：空气、表面、导体、场线或波前。
- 指定前缘、尾迹、衰减、反作用和环境响应。
- 不让同一能量体同时表现为液体、烟雾和电弧，除非写明清楚的状态转换。

## 5. 多镜头连续性

为镜头组固定特效连续性表：

`世界坐标流向、发射源位置、主风向、平均速度、发射强度、密度、粒径分布、主涡尺度、温度/亮度、寿命、耗散阶段、环境痕迹`

- 区分世界方向和画面方向。摄影机越过动作轴线时，画面左右可以反转，但世界流向必须由机位变化解释。
- 让后续镜头继承前镜头状态。下一镜头应表现经过相应时间后的平移、扩散、冷却、下坠和耗散，不重置成全新形状。
- 保持主风场连续；烟、灰、火焰、衣物、头发和植被必须响应同一主风向。
- 保持物理粒径和物质比例，只让焦距、透视和景别改变画面尺寸。
- 保持质量、源区强度、核心密度、尾迹稀释和沉积量逻辑。
- 延续高速扩张、减速、冷却、变暗、悬浮或沉降阶段，不无过渡跳相位。
- 延续焦痕、湿痕、碎片堆、漂浮灰尘、体积阴影、反射色染和服装状态。
- 保留同一个“运动签名”：主流向、核心与尾迹关系、粒径混合、涡旋尺度和耗散速度不变，只改变观察距离与局部细节。

## 6. 自检清单

### 因果与运动

- [ ] 是否存在明确发射源和触发事件？
- [ ] 初速度、继承速度和主流向是否清楚？
- [ ] 重力、风、浮力、压力、冲击力和吸力是否互不矛盾？
- [ ] 主涡和边缘小涡是否具有尺度层级？
- [ ] 轻颗粒和重碎片是否表现出不同惯性与阻力？
- [ ] 速度、密度、温度、亮度和结构是否逐步耗散？

### 空间与光照

- [ ] 是否正确碰撞、分流、附着、反弹和遮挡？
- [ ] 核心、边缘和尾迹是否具有密度与尺度梯度？
- [ ] 是否改变地面、水面、衣物、头发、植被和材质？
- [ ] 发光效果是否照亮邻近表面并合理衰减？
- [ ] 烟尘是否产生吸收、散射、体积阴影和色染？
- [ ] 人脸上的视效色染是否局部、有方向、被解剖曲面遮挡并随距离衰减？
- [ ] 皮肤是否仍保持真人软组织、区域性纹理和非均匀反光，而没有变成发光着色器？

### 连续性与意义

- [ ] 能否沿“源区—作用点—前缘—尾迹”读出运动方向？
- [ ] 是否保留一个清晰人物、动作或叙事锚点？
- [ ] 二次运动是否相对主动作存在可信滞后？
- [ ] 相邻镜头的世界流向、风场、粒径、密度和阶段是否连续？
- [ ] 每个下游现象是否能追溯到上游原因？
- [ ] 特效是否显示无形力量或代价，而不是只负责热闹？
