# 重写与剧本评估

## 目录

1. 评估顺序

## 1. 评估顺序

先判断剧本正在承诺哪部电影，再判断是否兑现。不要以个人偏好要求它变成另一类型。评估从上游到下游：

1. 独特命题与类型承诺
2. 主角行动与核心关系
3. 因果、升级与高潮选择
4. 世界规则与信息权限
5. 场景转折与节奏
6. 视觉/声音表达
7. 对白与格式

上游未成立时，不先做逐句润色。

## 2. 五条诊断曲线

通读后分别画出：

- **目标曲线**：主角目标何时建立、改变、收紧。
- **代价曲线**：身体、关系、身份、道德、时间代价是否递增。
- **主动性曲线**：重要事件中有多少由主角选择造成。
- **信息曲线**：观众的问题是否持续获得证据和更深问题。
- **关系曲线**：核心关系的信任、权力、亲密或恐惧是否变化。

若某曲线长段平坦，定位对应场景；若只在结尾突升，说明准备不足。

## 3. 场景审计

为每场写一行：`目标 / 阻力 / 策略变化 / 新信息 / 转折 / 余波`。无法填写三项以上的场景优先删、并或重写。

检查重复功能：连续两场都在证明“世界危险”、解释同一规则、让同一人拒绝主角。合并后让场景同时推进情节与关系。

检查“进入早晚”：若开头只是到达、寒暄、落座，迟进；若结尾已经解释完转折，早出。保留决定发生和后果落地的必要拍点。

## 4. 对白审计

标记：

- 已被画面表达的信息。
- 双方都已知道却互相说明的背景。
- 可以由行为替代的情绪句。
- 所有人相同的幽默或句式。
- 没有改变关系的金句。
- 问一句答一句的采访式结构。

重写时先改变角色策略和行动，再改台词。潜台词问题往往是场景目标不清，不是词不够含蓄。

## 5. 重写轮次

建议分轮：

- **第一轮：电影身份**。一句命题、类型承诺、独有视听机制。
- **第二轮：人物与因果**。主角、对手、关系、选择、高潮。
- **第三轮：结构与信息**。序列、伏笔、公平揭示、规则边界。
- **第四轮：场景**。目标、策略、转折、余波、场景合并。
- **第五轮：对白与节奏**。声音差异、潜台词、删重复。
- **第六轮：生产可读性**。格式、连续性、时长、预算风险。

每轮保留变更日志只在用户需要时提供；不要为了显得工作量大而输出冗长过程。

## 6. 反馈写法

先给结论，再给证据。每个问题使用：

```text
问题：
文本证据：
观众体验后果：
上游原因：
修改方向：
可保留的生命力：
```

区分事实、推断和偏好。不要只说“节奏慢”“人物扁平”“缺少电影感”；指出哪段目标消失、哪次选择无后果、哪个人物只传递信息、哪条规则临时出现。

修改建议分两层：先写不可缺少的戏剧功能（例如“建立可累计且不可逆的代价”），再写一个或多个明确标注为“可选示例”的实现方式。除非用户确认，不得把新增亲属、过去创伤、力量规则、阴谋者、死亡或结局当成正史，也不得直接写回源文件。优先测试能否通过重排、合并或强化现有设定完成修复。

最终评估至少回答：为何现在值得拍；最独有的部分是什么；最大风险是什么；下一轮最值得改的 1–3 件事是什么。
