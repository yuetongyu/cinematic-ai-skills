# 类型、世界观与改编

## 目录

1. 类型承诺

## 1. 类型承诺

类型不是美术标签，而是观众期待被影片反复激活的体验：

- 惊悚：信息不足、风险逼近、错误决定的代价。
- 悬疑：提出可追踪问题，证据不断改变问题。
- 动作：目标在物理空间中受阻，身体选择产生后果。
- 恐怖：安全规则失效，人物被迫面对不愿承认的恐惧。
- 喜剧：人物维护自我形象的策略持续与现实冲突。
- 爱情：两人靠近所需的改变，恰好威胁各自的自我保护。
- 奇幻/科幻：不可现实化的规则把现实中的价值冲突变得可见。

先兑现核心承诺，再变体。不要以“反类型”为由拒绝观众最基本的体验。

## 2. 悬疑与反转

建立三列：事实、人物解释、观众当前解释。每个关键证据应至少支持两个解释，后文不是推翻证据，而是改变其含义。

有效揭示会：

- 解释早期异常。
- 改变人物下一步行动。
- 改变关系或道德判断。
- 让观众觉得“我本可看见”，而非“作者没告诉我”。

悬疑问题要逐级变深：`发生了什么 → 谁造成 → 为什么 → 主角与此有何关系 → 知道真相后必须做什么`。如果谜底与主角选择无关，只是知识答案。

## 3. 奇幻科幻规则

规则先写成本与受益者，再写奇观。每项能力需要：触发条件、能力边界、可观察结果、使用代价、反制方式、留下的后果。能力越强，越要明确它不能解决的关系或道德问题。

世界观曝光采用“使用—失败—代价—推断”：

1. 人物自然使用规则。
2. 规则在意外条件下失败或反噬。
3. 有人承担可见代价。
4. 观众自行理解边界。

不要先讲全套规则再开始故事。

## 4. 动作与力量升级

动作场景需要：即时目标、空间地图、可用资源、限制、策略变化、人物选择、结束状态。每段动作必须让关系、信息或身体状态发生变化。

力量升级不能只更亮更大：

- 新能力暴露身份。
- 使用会消耗寿命、记忆、信任或不可再生资源。
- 能力解决敌人却伤害需要保护的人。
- 更强力量要求人物接受对手的价值或失去自主性。

动作高潮最好让人物用早期不起眼的职业能力、关系知识或世界规则解决，而非临时获得万能技能。

## 5. 恐怖、喜剧与爱情

**恐怖**：先建立安全习惯，再让异常精准侵入。怪物或异常应知道如何触碰人物独有的羞耻、关系或制度处境。随机怪脸只能惊吓，不能持续恐惧。

**喜剧**：人物越认真保护错误自我形象，场景越可笑。笑点后果要累计；如果所有尴尬下一场归零，喜剧不构成故事。

**爱情**：吸引不是互相赞美，而是对方既看见自己又威胁旧策略。每次靠近应暴露新的不兼容；高潮不是告白音量，而是一个人是否做出不可撤回的信任行动。

## 6. 改编原则

先识别原作不可替代的体验，而不是逐事件保留。分别列出：

- 必须保留的核心关系与主题压力。
- 只有文字/内心/叙述者能完成的效果。
- 可转译为行动、空间、声音、物件或结构的内容。
- 为电影时长必须合并、删除或重排的支线。
- 影视版本需要新增的持续目标和高潮选择。

忠实于因果、人物与体验，不等于忠实于每个情节。任何合并角色必须保留其原来承担的价值立场和因果功能。
