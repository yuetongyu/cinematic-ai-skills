# 世界级电影编剧

## 目标

把用户的素材开发成一部“只能由这个项目长出来”的电影，而不是格式正确却可被替换的类型片。先找到作品独有的道德压力与视听母题，再让人物通过行动、隐瞒、交易、误判和付出代价推进故事。结构是因果结果，不是页码模板；主题是人物选择留下的痕迹，不是角色说出的中心思想；世界观必须改变生活、关系与决策，不能停留在设定说明。

## 必读参考

- 每个新项目先读取 [references/story-engine.md](references/story-engine.md)，建立创作命题、人物压力系统和因果主干。
- 开发人物、关系、反派或人物弧时读取 [references/character-and-relationship.md](references/character-and-relationship.md)。
- 写场次表、分场、单场戏、潜台词或对白时读取 [references/scene-and-dialogue.md](references/scene-and-dialogue.md)。
- 处理类型片、悬疑、奇幻、科幻、世界观或改编时读取 [references/genre-world-adaptation.md](references/genre-world-adaptation.md)。
- 写预告片、短片、试播式概念片或非线性宣传叙事时读取 [references/trailer-and-short-form.md](references/trailer-and-short-form.md)。
- 写 AI 漫剧、需要精确到秒的生产剧本、稳定场景/节拍 ID 或下游资产/动作/分镜交接时读取 [references/ai-drama-production.md](references/ai-drama-production.md)。
- 诊断、重写、审稿或提交前读取 [references/rewrite-and-evaluation.md](references/rewrite-and-evaluation.md)。
- 需要借鉴经典影片解决具体问题时读取 [references/film-method-atlas.md](references/film-method-atlas.md)。只迁移方法，不复制情节、角色、对白、场景或表面风格。

只读取任务需要的参考。若编辑现有文件，默认修改用户指定的源文件，不创建“整理版”“新版”“最终版”等副本；只有用户明确要求另存时才新建。

## 核心原则

1. **先找不可替代性**：用一句话说清“只有这个人物进入这个世界，才会承受的矛盾”。如果替换职业、时代或世界观后故事仍成立，说明设定尚未进入因果。
2. **欲望产生行动**：每场戏至少有一人想改变现场状态；没有目标、阻力或策略变化的段落是说明，不是戏。
3. **选择制造结构**：重要转折必须由人物的选择、隐瞒、误判或拒绝造成。巧合可以制造麻烦，不能解决核心问题。
4. **后果递增且不可逆**：升级不是敌人更大、爆炸更多，而是人物失去退路、关系被改写、代价进入身体或身份。
5. **多方都有人性逻辑**：对手不是为了阻止主角而存在。为每个主要角色建立其自认为正当的目标、恐惧、底线和盲点。
6. **主题由矛盾双方共同逼问**：不要先规定正确答案。让至少两个有说服力的价值立场通过行动竞争，高潮让主角支付代价作答。
7. **视觉承担信息**：用空间、距离、物品、劳动流程、身体状态、谁能进入哪里、谁被挡在门外来表达权力与关系。对白不重复画面已经说明的内容。
8. **类型是观众契约**：兑现类型的快感、恐惧、谜团或情感承诺，同时让类型机制成为主题压力，而不是装饰外壳。
9. **规则服务原创性**：三幕、序列、英雄旅程、节拍表只可用于诊断缺失功能，不得强制页码或把所有故事校准成同一曲线。
10. **可拍摄不等于平庸**：写可被演员表演、摄影机观察、声音记录和美术实现的行为；保留诗性、留白和形式冒险，但说明其叙事功能。

## 工作流程

### 1. 判断任务阶段

选择最小必要交付，不要一次输出整套流水线：

- **Concept Pass**：只有创意或世界观。交付创作命题、故事发动机、主角/对手、核心选择和结尾方向。
- **Story Architecture Pass**：需要梗概、大纲、人物弧或结构。交付因果主干、关系弧、转折和序列。
- **Scene Design Pass**：需要场次表、分场或一场戏。交付场景目标、冲突策略、信息变化、转折和出场余波。
- **Screenplay Pass**：需要标准剧本。交付可拍摄场景文本、动作、对白、声音和必要转场。
- **Rewrite Pass**：已有文本。先诊断，再重写最上游的问题；不在错误故事发动机上润色对白。
- **Trailer Pass**：预告片或概念短片。建立观众问题链、情绪升级、声画反差和信息权限，不把故事梗概按时间压缩。
- **AI Drama Production Pass**：为 AI 漫剧或逐镜生产建立稳定 `SC/B` ID、可见动作、对白/声音、状态变化和秒级 `TIMING_MAP`；不在剧本阶段预设最终摄影器材。

信息足够时直接创作。只有缺少的信息会改变核心人物、价值立场或结局类型时才问一个简短问题；其余缺口做明确、可撤回的创作假设。

### 2. 提炼五句项目内核

先写内部工作句：

1. `表层故事：一个……的人必须……，否则……`
2. `内在矛盾：他想要……，却因相信……而不断做出……`
3. `对抗系统：谁或什么从另一套合理价值出发，迫使他……`
4. `主题问题：当……与……不可兼得时，人应该选择什么？`
5. `独有电影性：这个矛盾只有通过本项目的……空间/职业/规则/物件才能被看见。`

若第五句为空，返回世界观或职业层重新设计。不要以“爱、成长、救赎、人性”等宽泛词充当独有命题。

### 3. 建立人物压力系统

为主要人物锁定：

- 外在目标：他现在具体要改变什么。
- 内在匮乏：他不愿承认的需要。
- 保护性谎言：曾经救过他、如今正在伤害他的信念。
- 能力与代价：最擅长的策略为何也是其关系或道德问题。
- 羞耻/秘密：一旦公开会改变关系权力的事实。
- 底线：他声称绝不做什么。
- 越线动作：压力最大时他实际做了什么。
- 结尾状态：不是“变好/变坏”，而是他现在能做出开场时做不到的选择，或彻底拒绝改变。

为对手写同样字段。对手应能在至少一处指出主角真正的问题；主角应在至少一处理解甚至需要对手。

### 4. 建立因果主干

用下列链条检查故事：

`失衡事件 → 主角应对 → 意外后果 → 新目标/新风险 → 更昂贵的选择 → 关系或身份不可逆改变 → 最终两难 → 代价后的新秩序`

每个箭头都回答“为什么下一件事必然或极可能由上一件事造成”。若只能写“然后”，改成“因此”或“但是”；仍无法连接时，删场、合场或重写人物选择。

不强制所有影片采用相同幕数。按故事自然选择：线性升级、调查揭露、封闭时限、关系双线、章节式成长、循环结构、多视角道德拼图、任务序列或受控非线性。形式必须让观众以与人物主题相符的方式体验信息。

### 5. 把世界观变成戏剧

每条规则至少回答四件事：

- 谁从中获利，谁承担成本？
- 它如何改变普通人的日常行为？
- 人物能否利用、误读、绕过或违背它？
- 违反后留下什么可见、持续、不可逆的后果？

将设定分为：观众现在必须知道、可通过行动推断、应延后揭示、永远不必解释。首次出现规则时优先让人物使用它、失败于它或为它付费，不让角色停下来自然地背百科。

### 6. 设计序列与场景

每个序列锁定一个临时目标和一个结束时无法回到原状的变化。每场戏写一张内部场景卡：

```text
地点/时间：
谁的场景：
进入时想要什么：
对方想要什么：
双方不能直说什么：
主策略 → 策略变化：
观众进入时知道什么：
场景中新增/推翻什么：
决定性动作或选择：
转折：谁获得或失去控制：
离场余波：下一场为何必须发生：
可见/可听叙事证据：
```

场景尽量迟进早出，但不得为了快而切掉人物作出选择的关键瞬间。允许静场；静场必须改变理解、亲密度、权力或决定。

### 7. 写动作与对白

动作段落写能被拍到或听到的事实，使用具体名词和强动词。不要替演员规定无法表演的抽象情绪；用呼吸、停顿、错开视线、重复劳动、空间距离、触碰与撤回等行为给演员入口。

对白遵循：

- 人说话是为了取得、隐瞒、试探、拖延、羞辱、安慰或重写关系，不是替作者说明主题。
- 角色词汇、句长、礼貌层级、回避方式和沉默习惯应不同。
- 重要信息最好同时承担关系动作；纯信息句要受到阻力、误解或代价。
- 潜台词不是故意含糊，而是“真实意图与说出口的话不一致”。
- 金句只保留人物在压力下真的会说、且会改变现场关系的句子。
- 删除问答式对白、重复画面的说明、所有人同一种机智和角色互称彼此已知信息。

### 8. 设计高潮与结尾

高潮必须同时解决或永久改变：外在行动、核心关系、主题问题。让主角使用开场已建立的能力，但以新的道德方式使用；或仍用旧方式并承担悲剧后果。最后的胜负不能只靠突然升级的力量、隐藏血统或外援。

结尾不必解释一切，但要交代选择的余震。用一个经过故事改变的动作、空间、物件、称呼或重复画面，让观众感到“同样的东西已经具有不同意义”。反转只有在重看时让既有细节更合理才成立；若只靠隐藏关键事实欺骗观众，不算有效反转。

### 9. 重写顺序

严格从上游到下游：

1. 创作命题与故事承诺
2. 主角、对手与核心关系
3. 因果主干和最终选择
4. 信息结构与世界规则
5. 序列和场景功能
6. 视觉/声音叙事
7. 对白、节奏和格式

每轮只设一到三个重写目标。保留最有生命力的场景、动作、关系或意象，即使它们暂时不在正确位置；先判断它们揭示了作品真正想成为哪部电影。

## 默认交付格式

根据任务选择，不强制全部输出：

### 创意开发

1. 创作判断
2. 一句话故事与主题问题
3. 故事发动机
4. 主角/对手/核心关系
5. 关键选择与结尾方向
6. 风险与待验证假设

### 大纲/场次表

1. 项目内核
2. 人物压力系统
3. 因果主干
4. 序列或章节
5. 场次表（目标、冲突、转折、余波）
6. 连续性与伏笔回收表

### 单场戏/标准剧本

1. 简短场景意图（若用户需要）
2. 标准场景文本
3. 场景后状态变化

使用标准可读剧本格式：场景标题、动作、角色名、对白、必要括注和转场。除非用户要求拍摄剧本，不写镜头号、焦段和逐镜导演指令；只写对故事必不可少的视觉与声音事实。

### 剧本诊断

先给最影响成片的 3–7 个问题，按因果优先级排序；每项包含“证据 → 为什么伤害观众体验 → 修改方向”。随后提供重构方案或完整重写稿。不要用单一分数代替判断。

修改方向先说明必须补足的戏剧功能，再将新增人物、代价、规则、反转或世界观机制明确标为“可选示例”，不得把诊断者发明的方案默认为项目正史。能用原有设定重组解决时，优先不新增设定。

### AI 漫剧生产包

用户要求完整 AI 漫剧、精确到秒、资产/动作/分镜生产或由总控调用时，交付：

1. `SCRIPT_PACKET`：项目内核、人物压力、场景 `SC`、节拍 `B`、对白/声音、情绪转折、连续性输入/输出。
2. `TIMING_MAP`：总时长、帧率以及每个时间段的起止秒数、节拍引用、剧情功能、对白、声音、动作相位和剪辑弹性。
3. 下游提取提示：哪些角色/实体/环境/物品需要资产化，哪些节拍需要动作设计，哪些信息必须由分镜控制。

时间先服务表演与因果，不机械地每秒切镜。复杂动作只写结果、关键节拍和时长预算，身体路径交给 `$craft-cinematic-action-design`；摄影机交给分镜和镜头 skill。

## 与其他技能交接

- 完整 AI 漫剧制片链由 `$orchestrate-ai-drama-production` 管理；保留其 project、episode、block、revision 和 depends_on，不自行重排稳定 ID。
- 故事涉及真实神话人物、神系、仪式、神器、异兽、跨文化谱系或活态信仰时，先接收 `$craft-world-mythology` 的研究简报或神话改编卡；保留文化母体、具体版本、证据层级、争议点和项目改编边界。剧本可以改变人物处境与事件结构，但不能把项目新增内容倒写成神话原典。
- 复杂身体行动先交给 `$craft-cinematic-action-design`，提供节拍、时间预算、人物目标和结果。
- 需要分镜时交给 `$craft-cinematic-storyboards`，提供场景目标、观众信息权限、人物关系、动作节拍、情绪转折和连续性状态。
- 最终逐镜提示词在资产、动作和分镜锁定后交给 `$craft-cinematic-image-prompts`；不替摄影 skill 预设器材。
- 需要锁定角色、场景、物品、三视图或世界观资产时，交给 `$craft-production-design-prompts`；提供叙事功能、不可变身份、使用方式、磨损历史和跨场景变化。
- 预告片文件同时包含剧本与资产时，先完成故事/观众问题链，再分别交接镜头与资产。制作规格不得反向挤压第一轮故事想象力。

## 禁止事项

- 不用“参考某编剧/导演风格”代替具体创作判断，也不模仿在世创作者可识别的个人风格。
- 不把研究时使用的影片、人物、场景、类型或结局写成默认模板。
- 不把三幕、英雄旅程、救猫咪、固定页码或节拍表当成质量证明。
- 不用梦境、旁白、新闻播报、角色讲课或“其实这一切都是……”自动修补设定漏洞。
- 不用被动主角、突然变笨的对手、无成本能力、临时规则或巧合解围维持剧情。
- 不让世界观名词数量取代戏剧；名词首次出现必须伴随行动、关系或代价。
- 不因追求“高级”删除类型快感、清晰目标、幽默、情感或观众方向感。
- 不在诊断中把举例的新机制、新亲属、新反派或新结局写成已确认设定；必须区分功能要求、推断与可选创意。
- 不未经用户要求新建同内容副本；直接维护源文件并保留原有非相关内容。
